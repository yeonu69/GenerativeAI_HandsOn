# 「별빛극장」 종합 점검표

| 영역 | 점검 항목 | 결과 | 고친 내용·날짜 |
|---|---|---|---|
| 출처 | 영화 정보·데이터의 출처와 확인 날짜가 있는가 | | |
| 저작권 | 남의 작품·화풍·얼굴·목소리를 흉내 낸 것이 없는가, 약관을 확인했는가 | | |
| 개인정보 | 꼭 필요한 정보만 모으고, 남의 정보가 코드·데이터·주석에 없는가 | | |
| 보안 | 비밀 키 없음 · 권한 설정 · 입력 검사 · 횟수 제한 | | |
| 접근성 | 휴대폰 화면 · 대체 텍스트 · 자막 · 키보드 이동 · 글자 대비 | | |
| AI 표시 | AI로 만든 그림·영상·소리·답변에 표시가 있는가 | | |

## 사람이 직접 하는 시험
- 로그인하지 않은 창에서 남의 예매 정보를 읽거나 주문 상태를 바꿔 본다(막혀야 통과).
- 공개 저장소에서 key, secret, password를 검색한다(나오지 않아야 통과).
- 새어 나간 키가 있었다면 지우는 것만으로는 부족하다: 즉시 폐기하고 새로 발급한다.
