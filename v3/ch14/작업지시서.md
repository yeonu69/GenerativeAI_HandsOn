# 작업 지시서 예시

## 1. 안내 로봇 시뮬레이터 (메인 실습)
- 목표: 말로 된 명령을 계획으로 바꾸고 안전 규칙을 지키며 움직이는 안내 로봇 시뮬레이터
- 범위: robot-sim 폴더 안의 robot.html, tests.html만
- 완료 기준: tests.html의 안전 시험 5개 모두 통과
- 확인 지점: 계획(바꿀 파일·지울 파일 목록)을 먼저 보여 주고 승인받기, 명령 실행 전 묻기
- 하지 말 것: 파일 지우기, 저장소에 올리기(push), 외부 프로그램 설치, 비밀 키 다루기
- 보고: 무엇을 왜 고쳤는지 파일별로 요약

## 2. 「별빛극장」 깨진 링크 점검 (짧은 실습)
- 목표: 사이트의 모든 페이지에서 깨진 링크와 그림을 찾아 고친다
- 범위: byeolbit 폴더 안의 html·css 파일만
- 완료 기준: 링크 검사 스크립트를 돌렸을 때 깨진 곳 0개
- 확인 지점: 고치기 전에 찾은 목록을 먼저 보여 주고 승인받기
- 하지 말 것: 파일 지우기, 저장소에 올리기, 외부 프로그램 설치
