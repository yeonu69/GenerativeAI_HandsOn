# 프로젝트 규칙 (에이전트가 일을 시작할 때마다 읽는 파일)

- 이 폴더(robot-sim) 안의 파일만 읽고 고친다. 다른 폴더는 읽지도 쓰지도 않는다.
- 결과물은 HTML 파일 하나씩, 외부 라이브러리를 쓰지 않는다. 색은 남색(#1E2A5A)과 노랑(#FFC83D).
- 파일을 지우거나, 저장소에 올리거나(push), 프로그램을 설치하지 않는다. 꼭 필요하면 먼저 이유와 함께 묻는다.
- 안전 규칙(벽 통과 금지, 손님과 1칸 안이면 멈춤, 한 번에 1칸, 비상 정지 우선, 모르는 명령은 되묻기)은 계획과 상관없이 실행하는 매 순간 검사한다.
- 고친 뒤에는 tests.html의 안전 시험을 모두 돌리고 결과를 보고한다.
