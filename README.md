각 실험실의 탭은 주소 뒤의 `#이름`으로 바로 열 수 있습니다. 예: `labs/ch04/#sample`

## 구성

- `index.html` — 실험실 목차
- `labs/<장>/index.html` — 장별 실험실 (HTML 한 파일, 외부 라이브러리 없음, 글꼴만 Google Fonts)
- `labs/ch01/media/` — 1장 오프닝 영상

10~15장 실험실은 교재 집필에 맞춰 추가됩니다.

예시 데이터와 수치는 원리를 보여 주기 위한 모형이며 실제 AI 모델의 값과 다를 수 있습니다.
